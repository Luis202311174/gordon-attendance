# Gordon College BSIT 4D Attendance
1. Install Node.js (LTS), open this folder in VS Code.
2. `npm install`
3. Configure `.env.local` with your Firebase project keys.
4. Ensure your Firebase Realtime Database Security Rules allow read/write.
5. `npm run dev` then open the URL shown (usually http://localhost:5173).
Live attendance records and session updates are synced in real-time with Firebase.
